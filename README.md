# Ну, погоди! — Электроника ИМ-02

[Играть в браузере](https://positron48.github.io/nu-pogodi/)

Веб-версия на **оригинальной прошивке**: браузер эмулирует КБ1013ВК1-2 / Sharp SM5A и показывает 72 сегмента оригинального ЖК-экрана. Яйца, ускорение, счёт, штрафы, рекорды, игры А/Б, часы и будильник управляются исходной программой устройства. Отдельного алгоритма игры в JavaScript нет.

## Запуск

Откройте `index.html` двойным щелчком. Сервер, сборка, установка пакетов и интернет для игры не нужны. Все изображения, прошивка и скрипты лежат рядом с HTML.

При желании запустите локальный сервер (Node.js 22+):

```sh
npm start
```

Адрес: http://localhost:4173.

## Язык интерфейса

Переключатель «Русский / English» меняет язык без перезапуска игры и сохраняет выбор. Язык в ссылке имеет приоритет: [English](https://positron48.github.io/nu-pogodi/?lang=en), [Русский](https://positron48.github.io/nu-pogodi/?lang=ru). Без параметра используется сохранённый язык, по умолчанию — русский. Оригинальные надписи на корпусе сохранены; инструкция поясняет их на английском.

## Управление

| Действие | Клавиша / кнопка |
| --- | --- |
| Корзина слева вверху / внизу | Q / A |
| Корзина справа вверху / внизу | P / L (также O для правого верха) |
| Начать игру А / Б | 1 / 2 или кнопки на корпусе |
| Время | T |
| Настройка будильника | B или маленькая кнопка под колокольчиком |
| Настройка времени | Маленькая кнопка под значком часов |
| Пауза / продолжение | Пробел или кнопка под корпусом |
| Звук | M |
| Полный экран | F |

Раскладка клавиатуры может быть русской: используются физические позиции клавиш. Все штатные кнопки работают мышью и касанием, в том числе одновременно. На телефоне удобнее горизонтальная ориентация.

После нажатия маленькой кнопки часов левые красные кнопки меняют часы, правые — минуты. «Время» завершает настройку. Будильник настраивается аналогично; повторное нажатие кнопки с колокольчиком включает/выключает звонок. ДП/ПП обозначают половины суток.

Звук включается после первого действия пользователя. При скрытии вкладки, открытии инструкции или ручной паузе эмуляция останавливается вместе с часами. Перезагрузка страницы заново включает устройство и обнуляет память и рекорды; сохраняются настройки звука и языка.

## GitHub Pages

Без сборки:

1. Загрузите проект в GitHub-репозиторий.
2. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**.
3. Укажите свою ветку и каталог **/(root)**.

С автоматическими проверками и публикацией:

1. В **Settings → Pages → Source** выберите **GitHub Actions**.
2. Отправьте проект в ветку `main` или `master`.
3. Workflow `.github/workflows/pages.yml` запустит тесты, соберёт `dist/` и опубликует его.

Выберите один из этих вариантов. Все пути относительные: адрес вида `https://USER.github.io/nu-pogodi/` работает без правок конфигурации.

Для другого статического хостинга выполните `npm run build` и загрузите содержимое `dist/`. Backend, ключи и переменные окружения не нужны.

## Проверки и исходники

`npm test` запускает 18 тестов: прошивка, инструкции CPU, память, таймер, ЖК-инерция, кнопки, лотки А/Б, обычные и половинные штрафы, сбросы на 200/500, переход через 999, рекорды, часы, будильник и звук.

Интеграционные тесты проходят игру виртуальными нажатиями, наблюдая сегменты яиц. Они не меняют RAM, ROM или правила. Автопилот находится только в `tests/` и не входит в сборку.

- `js/sm5a.js` — CPU, делитель, порты и ЖК-сегменты.
- `assets/im-02.bin`, `js/rom.js` — исходная прошивка и её копия для `file://`.
- `assets/lcd.svg`, `js/artwork.js` — архивные сегменты и браузерная версия.
- `js/app.js` — ввод, вывод, Web Audio и браузерная пауза.
- `assets/*.png` — корпус и слои экрана.
- `scripts/prepare-artwork.py` — подготовка SVG; нужен только при изменении исходной графики.
